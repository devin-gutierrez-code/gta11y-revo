## Landing-gear semantics

Read out of `pilot_school.c`, not taken from a community native list. The polarity
is the part that matters: reversed, an assist retracts the gear on final approach.

The decisive site is `pilot_school.c:114940` —
`if (IS_ENTITY_IN_AIR(veh) && GET_LANDING_GEAR_STATE(veh) == 0) CONTROL_LANDING_GEAR(veh, 1)` — which fixes read-state 0 as DOWN and
write-command 1 as RETRACT in a single statement.

| GET_LANDING_GEAR_STATE | meaning | evidence |
|---:|---|---|
| 0 | deployed | pilot_school.c:114940 retracts when in air and state==0; pilot_school.c:113973 treats 0 and 3 as the gear-down test |
| 1 | retracting/up | pilot_school.c:107352 groups 1 with 4 as the gear-up branch |
| 2 | unused in corpus | no call site observed |
| 3 | deploying/down | pilot_school.c:106696 tests != 3 && != 0 for 'not down' |
| 4 | retracted | pilot_school.c:114585 accepts state==4 as the gear-up success condition |
| 5 | broken | pilot_school.c:106692 and the IS_PLANE_LANDING_GEAR_INTACT branch at 107352 |

| CONTROL_LANDING_GEAR | meaning | evidence |
|---:|---|---|
| 0 | deploy | pilot_school.c:114174 lowers gear while placing a plane on the runway |
| 1 | retract | pilot_school.c:114942, in air with state==0 |
| 2 | set deployed instantly | pilot_school.c:93285, teleporting a plane onto the ground |
| 3 | set retracted instantly | am_plane_takedown.c:580 and re_seaplane.c:2960, both airborne spawns |
| 4 | set broken | pilot_school.c:107959, the else-branch when gear was already damaged |

Rockstar gates every gear call on `GET_VEHICLE_HAS_LANDING_GEAR` and
`IS_PLANE_LANDING_GEAR_INTACT` (`pilot_school.c:107350`). So does this mod, and a
gear reading 5 (broken) is spoken aloud rather than silently worked around — a
blind pilot has no other way to know the landing is going to be bad.
